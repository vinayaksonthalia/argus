# ARGUS brand

![ARGUS](logo-1200.png)

**The mark.** A geometric eye whose iris is a live radar scope — a scanning sweep beam
rotates inside the pupil ring, framed by a broken outer radar arc. It fuses the
Argus-the-hundred-eyed-watchman idea with the reality of observability: not a passive eye,
but an aperture actively *scanning* for the next incident. Drawn on a 64×64 grid with a
consistent 4px primary stroke, round joins, and a single accent (violet `#8B5CF6`) plus a
same-hue sweep gradient — no other colors, no drop shadows.

**Files.** `icon.svg` (square, 0 0 64 64) is the master mark and works on both light and
dark backgrounds via the accent color. `logo.svg` / `logo-dark.svg` are the horizontal
lockups (mark + `ARGUS` wordmark, Inter 600, +2.4 tracking, all caps) for light and dark
surfaces respectively. PNG renders: `icon-512.png`, `icon-64.png` (transparent), and
`logo-1200.png` (on the `#0A0B0D` brand canvas).

**Usage.** Keep clear space around the mark equal to the pupil diameter. Never recolor the
accent to a severity color (red/amber/green are reserved for status, never brand). Use the
icon alone at ≤32px; use the lockup wherever the name should read. Don't add shadows,
outlines, or a second accent.
